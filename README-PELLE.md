# Что куда загружать (сайт «Пэлле и Вася» + выбор сайта)

**Пароль входа на сайт Пэлле: `pelle-vasya`** (хэш уже вписан в pelle/*.html). Сменить: открыть gate/make-hash.html, ввести новый пароль и заменить значение data-hash во всех pelle/*.html (6 файлов).
Редактировать сайт Пэлле может админ: 👤 в шапке → войти аккаунтом `ventyan` (тем же паролем, что на сайте про новеллу) → «Включить режим редактора».

## Загрузить в корень репозитория (заменить/добавить)
- `index.html` — НОВАЯ первая страница: выбор сайта (новелла / Пэлле и Вася / скоро)
- `home.html` — бывшая главная новеллы (раньше была index.html)
- `js/pages.js`, `js/shell.js` — обновлены (ссылка «Главная» → home.html, кнопка возврата)
- `hub/universes.js` — список вселенных (новая вселенная = одна строка); `hub/index.html` — перенаправление
- `gate/exit.js` — кнопка «Вернуться на главную страницу» + экран «Завершение работы» (общая для обоих сайтов)
- `database.rules.json` — скопировать содержимое в Firebase → Realtime Database → Rules (добавлена ветка `pelle`)
- Папка `pelle/` целиком: index/world/chars/diary/gallery/page .html, theme.css (оформление — только переменные), data.js (лор), core.js (меню SECTIONS, база, вход, редактор), views.js (страницы)
- Папка называется `pelle/` (как зовут героиню). Если в репозитории осталась папка `palle/` из прошлой попытки — удалите её.

Остальное (спрайты, mp3, ваши картинки в репозитории) не трогайте — в архиве их нет.

## Как добавить раздел-файл на сайт Пэлле
1. Скопировать pelle/gallery.html → pelle/новый.html, поменять `data-page` и title.
2. В views.js добавить функцию в VIEWS с тем же именем. 3. В core.js дописать строку в SECTIONS.
Без файлов: 👤 → «Редактор сайта» → «Новый раздел сайта».

## База данных
Данные Пэлле лежат в `pelle/<коллекция>/<id>` (chars, species, diary, gallery, pages, likes/<пост>/<человек>, comments/<пост>/<id>, cfg/main). Пользователи берутся из `site/users` сайта про новеллу.
Предупреждение: правила базы открыты для записи (как и у новеллы), а вход по паролю — не настоящая защита статического сайта.
